A Question and Your First Program

By Bishal Giri. Opening excerpt from Build Your First AI Agent with Python.

What you will build

You will create a small working folder and a Python program that displays the company name and a customer question. You will run it, change one line and run it again. No cloud account, AI service or database is needed.

Story. Alex has found the damaged-chair message. Before building an assistant, you ask Alex to show you the question and the policy a colleague would use. This is a useful first engineering habit: understand one ordinary task before choosing tools for it.

1.1 Start with the person, not the diagram

The customer asks, "What should I do about a damaged chair?" Alex wants to explain the reporting process. Sam wants to make sure the answer does not promise a refund that nobody has approved. These needs give the program a purpose and a limit.

The supplied returns policy says to report the damaged chair within seven calendar days, supply the order number and clear photographs, and wait for review. The assistant may explain the process; it cannot approve the refund. We will open the actual file after preparing the working folder below.

A document can be read by a person before any program exists. Keep that idea in mind: our first task is to understand the source, not to make a model guess what a source might say.

For now, draw three boxes on paper: question, policy, answer. Write the reporting period under the policy. Write "review required" under the answer. You have made a small architecture sketch: a picture of the parts and how information should move between them.

End of opening excerpt. The chapter continues with your editor, Python installation and first program.
