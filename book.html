WHO THIS BOOK IS FOR

A practical starting point
for your first assistant.

For students and beginners with little programming experience who want to understand how an AI assistant works by building one.

Start with files, a terminal and small Python programs. Then learn to search documents, keep evidence beside answers, connect read-only tools through the Model Context Protocol (MCP), and build an agent with a bounded tool loop.

The project grows into a browser application with sign-in, a shared AWS knowledge store, live SharePoint documents and permitted Salesforce records. Retrieval-augmented generation (RAG), identity and tool access are introduced as you need them.

Each chapter explains the need, introduces a short concept, gives exact actions, shows what to inspect and finishes with a checkpoint. Diagrams and troubleshooting guidance help you follow the changes.

Author: Bishal Giri. The book develops his project and concept into a guided learning route.

Before you begin

Do I need programming or cloud experience?

No prior agent, Docker or cloud experience is assumed. You start with basic files and Python. The main command route uses 64-bit Windows and PowerShell.

Can I start without paying for AI services?

The first four chapters run locally without paid AI-model calls. Later integrations require your own authorized accounts, permissions and any applicable cloud or model charges.

What is included with the book?

The book provides explanations, build instructions, diagrams and troubleshooting. This website provides the complete companion source, fictional practice data and twelve chapter resource packs.
