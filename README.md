# 84 Systems Lab — book resources

Static companion website for **Build Your First AI Agent with Python**.
No installation, dependencies, build step, analytics or backend.

## Preview

From this directory: `python -m http.server 8765 --bind 127.0.0.1`.
Open http://127.0.0.1:8765. Stop the server with Ctrl+C.

## GitHub Pages

Create the organization `84-systems-lab` using GitHub Free, then an empty public
repository named `84-systems-lab.github.io`. Commit these files and push main.
In Settings → Pages, select Deploy from a branch → main → / (root).
The intended address is https://84-systems-lab.github.io/; verify deployment
before using it in print. The name and address are not evidence of deployment.

## Updating resources

Keep all twelve chapter packs, the complete companion, CHECKPOINTS.json and
downloads/CHECKSUMS.sha256 synchronized as one snapshot. Verify hashes and ZIP
integrity before release. Preserve earlier published snapshots for existing readers.
The chapter packs supplement the complete source; they are not complete app checkpoints.

Only the cover preview and companion resources are included. The full book,
private author records, credentials and original reference application are excluded.
Do not upload .env files or Terraform state. No open-source license grant has
been invented: the companion's existing notices apply to its files.
