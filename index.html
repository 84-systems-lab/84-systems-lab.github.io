FROM THE BOOK

A practical guide
for your first build

Start with a question.
Learn to build the answer.

An office assistant needs to answer a simple question about a company policy. Where should the answer come from? How can a reader check it? What changes when the information belongs to a signed-in user?

Build Your First AI Agent with Python follows those questions from a small Python program to a complete enterprise assistant. You begin with files and functions, then add supported answers, read-only tools and an agent that chooses its next step within clear limits.

The later chapters connect a shared knowledge store, live documents and business records. Retrieval-augmented generation (RAG) brings relevant evidence into an answer. The Model Context Protocol (MCP) gives tools a shared interface. The book introduces each idea when you can use it.

You do not need to understand the whole system before you begin. Make one part work, inspect the result, and use what you learn to build the next part.

Each chapter combines a short concept, an exact action, an observable result and a checkpoint. When something fails, the next useful question is specific: which file ran, which identity was used, and what evidence did the program receive?

03 / KEEP GOING

Curiosity is part
of the process.

Something did not work?

Ask a question, report a correction or share feedback →

Return to the chapter’s last successful checkpoint. Check your current folder, file name and selected Python environment. Read the first error before changing several things at once.

When reporting a problem, include the chapter, step, command and redacted error text. Never share passwords, tokens, private documents or your .env file.

Understand before you deploy.

The early exercises run locally. Later chapters introduce Docker, AWS, identity and live integrations. Follow their access, cost and cleanup instructions before creating resources.

A working local exercise is your next step toward understanding the complete system. Change one small thing, predict the result, then try it.

Which files should I use?

Use the complete companion ZIP as your reference source and the chapter packs for focused resources. Follow the book’s file maps and build order. Do not copy every finished file into your first exercise.

Does the website include the book?

This site provides the supporting project files. The book contains the explanations, exact build steps, diagrams and troubleshooting guidance.
